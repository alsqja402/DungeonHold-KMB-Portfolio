# 스크린샷·영상 추가 가이드

[README](../README.md)

현재 깨진 이미지 링크 대신 촬영 목록을 제공하며, 실제 이미지는 아직 포함하지 않았습니다. 검토한 캡처는 `docs/media/`에 넣고 Markdown 상대 경로로 연결할 수 있습니다.

| 자료 | 보여줄 내용 |
| --- | --- |
| 대표 이미지 | 설치물·적·플레이어가 함께 보이는 Stage 3 전투 |
| 전체 영상 | 준비 → 설치 → 웨이브 → 석상 붕괴·보스 → 결과 |
| 설치 비교 | 유효·불가·회전·재화 부족·수량 제한 |
| 포탑 | 프리뷰 → 실제 설치 → 장전·발사 |
| 적 AI | 일반 적 4종·반격·경로 복귀 |
| Stage 2 | A/B·C/D·E/F·G/H를 묶은 탑뷰 |
| Stage 3 | 석상 경로와 출구 경로 전환 |
| 보스 | 전조 원·타격·회피·1회 발동 |
| 석상 연출 | 균열·빛줄기·파편·보스 등장 |
| 문제 해결 | 빠른 적 오류 로그와 같은 구간 재확인 |
| 최적화 | 같은 시야의 그림자 비교·ON/OFF 프레임 그래프 |

원본 에셋 파일 대신 실제 게임 실행 캡처를 사용하고, 팀 화면 전체를 개인 단독 구현으로 소개하지 않습니다. 개인정보·절대 경로·비공개 채팅이 노출된 부분은 제외합니다. 성능 그래프에는 에디터·빌드 여부와 비교 조건을 적습니다.

예시 연결 문법:

```md
![Stage 3 전투와 설치물](media/stage3-combat.png)
```

이미지를 실제 추가한 뒤 README에 연결합니다. 대용량 영상은 공개 가능한 영상 링크로 제공합니다.
